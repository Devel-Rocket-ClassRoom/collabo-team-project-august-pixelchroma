# MainGame 기획서 (Grid Top-view SRPG)

## 개요
- **장르**: Grid 기반 Top-view SRPG
- **비주얼**: 배경 3D + 캐릭터 2D (2.5D 스타일)
- **화면 구성**: 세로형(Portrait)
- **씬**: `Assets/1.Sence/4.MainGame.unity`

## 그리드 규격
- **가로(X)**: 5칸 (0 ~ 4)
- **세로(Y)**: 6칸 (0 ~ 5)
  - Player 배치 영역: Y = 0 ~ 1 (하단 2줄)
  - Enemy 배치 영역: Y = 4 ~ 5 (상단 2줄)
- 진행 방향
  - Player: 하단 → 상단 (Y 증가 방향)
  - Enemy: 상단 → 하단 (Y 감소 방향)

## 게임 진행 순서

### 1. 배치 단계 (Deployment Phase)
- **Player**
  - 캐릭터 4명을 하단 배치 영역(Y = 0~1)에 수동 배치
  - 전원 배치를 완료해야 게임 시작 가능
- **Enemy**
  - 자동 배치
  - X: 0~3, Y: 0~3 범위 내 랜덤 좌표 배치
  - 오브젝트끼리 겹치는 배치 불가 (좌표 중복 금지)

> 참고: Enemy 랜덤 배치 좌표 범위(X 0~3, Y 0~3)는 상단 배치 영역(Y 4~5) 기준과 별도로 재검토 필요.

### 2. 전투 단계 (Battle Phase)
- 배치가 끝나면 게임 시작
- **Player**: 하단에서 상단으로 상승하듯 진행
- **Enemy**: 상단에서 하단으로 하강하듯 진행
  - **이동 알고리즘**: A* 사용, Player를 추적(Chase)하는 방식
- **이동력**: 기본 3칸 (4방향 기준, 3x4 형식)
- **공격력**: 이동력과 유사한 방식으로 산정 (3x4 형식)

### 3. 종료 조건 (End Condition)
- 매 턴 종료 시 양 진영의 생존 오브젝트 수 판정
- **승리**: Enemy 전멸 (Player가 1명 이상 생존)
- **패배**: Player 전멸 (Enemy가 1명 이상 생존)
- 둘 다 1명 이상 생존 시 게임 계속 진행
